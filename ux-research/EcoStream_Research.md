# UX Research: EcoStream Dashboard

## 👤 User Personas
### Alex, 24 - The Eco-Conscious Professional
- **Goals:** Wants to track monthly carbon footprint without manual data entry.
- **Pain Points:** Existing apps are too "preachy" and have cluttered UIs.

## 🗺 User Journey Map
1. **Awareness:** User connects smart home devices.
2. **Engagement:** User views daily energy consumption vs. neighborhood average.
3. **Action:** User receives a notification to switch to eco-mode.

## ✏️ Wireframes (Low-Fidelity)
- Sidebar navigation for quick access.
- Central widget for "Total Impact" score.
- Secondary grid for detailed metrics (Water, Waste, Electricity).
