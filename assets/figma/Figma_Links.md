# 🎨 Figma Design Integration

This project uses Figma as the primary design tool for rapid prototyping and high-fidelity iterations.

## 🔗 Interactive Prototypes
Since Figma files are cloud-based, you can view the live prototypes and design specs via the links below:

### 1. [Fintech Mobile App - "NeoBank"](https://www.figma.com/community/file/1163452047391784534)
*   **Focus:** Dark mode, accessibility, and complex data visualization.
*   **Key Flow:** Peer-to-peer transfer and stock portfolio tracking.

### 2. [Health & Wellness UI Kit](https://www.figma.com/community/file/1105435942203524653)
*   **Focus:** Soft gradients, rounded corners (friendly UI), and typography hierarchy.
*   **Key Flow:** Booking a consultation with a specialist.

### 3. [Travel Explorer - Desktop Web](https://www.figma.com/community/file/1023524653000000000)
*   **Focus:** Immersive imagery, card-based layouts, and search filtering.

## 🛠 How to Use These Files
1.  **Duplicate to Drafts:** Click the "Open in Figma" button on the community links.
2.  **Inspect Mode:** Use the "Inspect" panel to see CSS values, spacing, and asset exports.
3.  **Prototype Mode:** Press `Play` (top right) to experience the interactive user flows.
