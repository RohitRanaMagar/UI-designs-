Accessibility Guidelines

Color Contrast

  • Body #1a1e24 on white: ratio 15.3:1 (AAA)
  • Secondary #5a6a7a on white: ratio 5.2:1 (AA)
  • Interactive states include hover/active/focus

Touch Targets

  • Minimum 44x44px for interactive elements
  • Buttons: 44px+ height
  • Form inputs: 48px+ height
  • Focus rings for keyboard navigation
